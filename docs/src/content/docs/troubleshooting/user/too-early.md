---
title: The result shows before the dice land
description: The setting that shows chat messages without waiting for the dice.
---

GM settings are in the Dice So Nice! section of **Module Settings** (see [GM Settings](/foundryvtt-dice-so-nice/guide/getting-started/#gm-settings)). Player settings are in the [Preferences](/foundryvtt-dice-so-nice/guide/preferences/) tab of the Dice So Nice! dialog.

- **Display chat message immediately** (GM, off by default) - Chat messages show at once, without waiting for the dice.

If it's off and a chat message still shows its result early, it comes from your game system or a module: report it to them. Their developers can check [The result shows before the dice land](/foundryvtt-dice-so-nice/troubleshooting/dev/result-shows-early/).
