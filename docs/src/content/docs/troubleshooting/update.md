Many problems are already fixed in a newer version, so update before anything else.

## Check your version

On the Foundry setup screen, the **Add-on Modules** tab shows the version of each module.

## Update

In the same tab, click **Update All**, or update Dice So Nice! on its own.

## On Foundry v13

The last version for Foundry v13 is **5.3.4**. Foundry v13 offers the newest version instead, which needs Foundry v14, and never offers 5.3.4 ([Foundry issue #7547](https://github.com/foundryvtt/foundryvtt/issues/7547), fixed in Foundry v14). To get it, uninstall Dice So Nice! and install it again: the install picks the last version that works with your Foundry.
