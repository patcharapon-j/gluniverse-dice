## Test without the other modules

Turn off every module except Dice So Nice! and your game system, then roll again. If the problem is gone, another module is involved: turn the modules back on a few at a time to find which one. The [Find the Culprit!](https://foundryvtt.com/packages/find-the-culprit) module does it for you.

## Report it

Open an issue on [GitLab](https://gitlab.com/riccisi/foundryvtt-dice-so-nice/-/issues) with:

- your Foundry version
- your Dice So Nice! version
- your game system and its version
- the steps to see the problem
- the errors of the browser console (F12), if there are any
